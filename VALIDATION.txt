environment using the published setup scripts and pinned SONIC 1.1 revision.
Package-download caches were reused; the venv and editable packages were new.
GPU checks ran on Linux x86_64 with glibc 2.39 and an NVIDIA RTX PRO 6000
Blackwell Max-Q Workstation Edition GPU.

Passed:
- Core package versions and import of this checkout's vendored rl_games.
- SHA-256 checks for all six SONIC 1.1 model/config files.
- Native 32-level FSQ projection and hand synergy contract.
- Batched Torch decoder versus official ONNX: maximum error 8.34e-07.

  invalid physics transition received the configured -5 reward.

  checkpoint creation and finite TensorBoard scalar values.

  MLP/LSTM at seeds 42/43 and preserves CUDA_VISIBLE_DEVICES.
