Clone it onto persistent shared storage accessible from GPU nodes. Read the
root README.md, SLURM_SETUP.md, SOURCE_PROVENANCE.json, and setup scripts.

G1/Wuji/SONIC implementation and vendored rl_games fixes.

Python 3.11.16 venv, installs Isaac Sim 5.1.0.0 / Isaac Lab 2.3.2.post1 /
PyTorch 2.7.0+cu128, and downloads pinned SONIC 1.1 weights. The robot URDFs
and meshes are already committed; source rebuilding is optional. Keep the
root layout with models/ alongside simtoolreal/. Respect the documented
dependency overrides and the editable root installation with --no-deps.

Preserve the current experiment:
- Free-standing G1, original Wuji hands on both wrists; right hand used first.
- Frozen SONIC 1.1; 64 normalized body outputs quantized to its native FSQ
  grid before decoding, plus 3 continuous right-hand commands.
- Hand commands: thumb rotation, thumb bending, shared four-finger bending.
- Actor 432D / privileged critic 454D; actor gets the current observation
  and previous action, while SONIC retains separate 10-frame history.
- MLP [1024, 512, 256, 128] ELU; LSTM alternative uses one 1024-unit layer
  before that MLP and sequence length 16.
- 128 environments, 200 Hz physics, 50 Hz control.
- Marker lift task Isaacsimenvs-G1-Wuji-Sonic-Lift-v0, lowered table and
  object positions as configured.
- Existing reward weights, object bounding boxes, success criteria,
  exploration settings and physics guards. There is no upright reward.
